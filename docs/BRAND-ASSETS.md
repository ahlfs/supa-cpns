# Brand assets

The SUPA CPNS brand mark is a **blue cloud**. Everything in `public/assets/`
under the paths below is either generated by this repo or vendored from a
permissively licensed icon set — nothing here comes from a third-party brand.

## The cloud mark and its provenance

The cloud silhouette is the **Tabler Icons filled cloud** path
(`tabler/tabler-icons`), embedded inline in the generator. Tabler Icons is
released under the **MIT licence**; the licence text lives at
<https://github.com/tabler/tabler-icons/blob/main/LICENSE>. The glyph is used as
a single `<path>` on a `0 0 24 24` viewBox.

Every other shape in these files — the rounded panels, the exam-room card, the
navigator grid, the score bars, the four program-card glyphs, the type
placements — is original vector work produced by the script below.

The palette is this app's own Tailwind theme (`resources/css/app.css`, the
`@theme` block): `brand #0657a8`, `brand-dark #063d78`, `accent #ff831f`,
`accent-dark #e67215`, `peach #ffedd5`, `ink #17212b`, `body #2b2b2b`,
`muted #5d6b7b`, `surface #f5f8fc`, `line #dce5ef`, `success #15803d`,
`warning #b45309`, `danger #c2410c`. Brand blue dominates; `accent` is an
accent only.

## Regenerate

```
node tools/build-brand-assets.mjs
```

The script writes every file in the "generated" table, prints each path with its
byte size, and exits 0. It needs no network access — the only things it uses
besides itself are the repo's own `playwright-core` and the chromium build
referenced at the top of the file (override with `SUPA_CHROMIUM=/path/to/chrome`).

The four program cards are one set: identical panel shape, gradient family,
glyph size and label typography. They differ only in the glyph and in a hue
rotation of the brand gradient (0°, +8°, −7°, +16°).

Two generated files were retired: `img/hero.svg` (the hero's product shot) and
`img/prefooter.svg` (the phone in the closing band). Both were second copies of
the exam room that `img/app-preview.svg` already draws, so the homepage shows that
picture once. They are recoverable from git history, along with the two builder
functions that drew them — re-adding one means restoring both the function and its
`put()` line.

Inside an SVG loaded through `<img>` only generic families resolve, so every
`font-family` in these files is
`Quicksand, Barlow, Helvetica, Arial, sans-serif` and the render falls back to
the generic sans-serif. The app's own webfonts are unaffected by that: nothing
here is inlined into a Blade view's CSS.

## Vendored — committed once, never written by the script

These are **Lucide** icons (`lucide-static`, **ISC licence**), downloaded once
from `https://cdn.jsdelivr.net/npm/lucide-static@latest/icons/<name>.svg`. Each
file keeps its upstream `<!-- @license lucide-static vX - ISC -->` comment as its
first line, keeps the upstream `0 0 24 24` viewBox, and only changes the
consumption attributes: `width`/`height` pinned, `stroke="currentColor"`
replaced with a literal stroke colour (they are consumed as `<img>`, where
`currentColor` cannot resolve), `stroke-width="2"`, `fill="none"`.

The stroke colour is `#0657a8` for every icon except the four `floating/float-*`
props, which are `#ffffff`: since the hero's product shot was removed they sit on
the brand-blue panel alone, and at brand blue they disappeared into it.
